# 基于DQN算法的网约车动态寻客路径推荐在多种攻击场景下的对抗评估研究

## 简介

本项目为毕业设计核心实现代码，聚焦基于深度Q网络（DQN）的网约车动态寻客路径推荐算法，并针对该算法构建多种攻击场景，完成算法在对抗环境下的鲁棒性评估。核心目标是验证DQN驱动的路径推荐算法在面对恶意攻击时的性能表现，为网约车路径推荐系统的安全部署提供理论与实验支撑。

## 算法说明

#### 概率分布模拟动态定价：

- 基于真实城市网格数据（900 个网格区域）构建动态环境

- 统计各网格区域的平均动态定价，划分为不同价格水平

- 依据历史订单数据计算各网格的接客概率分布

- 状态包含网格位置、时间、价格水平、接客概率、寻客时间占比、运输时间占比等8维特征

- 动作空间为9个方向的移动选择

#### Q-learning网约车寻客路线推荐

- 采用CNN+GRU+Attention的时空特征编码器，有效提取序列状态信息

- 使用优先经验回放（PER） 机制，提高重要样本的采样概率

- 实现Double DQN架构，缓解过估计问题

- 支持对抗训练正则化，通过FGSM、PGD和随机噪声攻击提升模型鲁棒性
### 鲁棒性评估方法
- 设计多维度评估指标：总收益、订单数、单位时间收益、收益效率、车辆利用率

- 定义性能损失比指标，量化攻击下算法性能的衰减程度

- 对比DQN与传统Q-learning在相同攻击场景下的表现差异

## 注意事项

在使用DQN进行路线推荐时，建议通过合理的参数配置和模型训练来获得更好的效果。
